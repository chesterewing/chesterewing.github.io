Personal Portfolio

The Problem

Resumes are flat. LinkedIn is a CV with extra steps. I needed a place online that could show what I do, how I think, and how to reach me, without dumbing any of those down. Most importantly, it had to be easy enough to update that I'd actually keep it current.

Goals

  • Show, not just tell: live links, real projects, public client demos
  • Manifest-driven content (Tools, Showcase, Writing, Testimonials) so updating is a JSON edit, not an HTML rewrite
  • Restrained, not decorated: one accent color, no gradients, nothing that moves for its own sake
  • Fast everywhere: installable PWA, mobile-first, zero dependencies
  • Never stale: durations compute from a start date rather than being typed in

Architecture

Static HTML pages, one shared app.js for everything dynamic (nav, theme toggle, scroll reveal, tenure counters, manifest loaders, capacity meter, scope estimator, contact form). Every module is guarded by its own DOM hook, so each page runs only what it needs. Content for Tools / Writing / Showcase / Testimonials lives in JSON manifests. Adding an entry is one file edit.

The 2026 rebuild cut the dependency tree to nothing: jQuery, Bootstrap, Owl Carousel, Magnific Popup, Modernizr, respond.js and SweetAlert2 all came out, and custom.css went from 268 KB to a single token-driven stylesheet. Twelve pages became five.

Tech Stack

  • HTML5
  • CSS3
  • JavaScript
  • CSS Grid & custom properties
  • PWA / Service Worker

Key Decisions

  1. Static, not SSR. No build step, no server needed, hosts anywhere. The cost is no per-page personalization, fine for a portfolio.
  2. One CSS file with design tokens. Dark and light both live in :root variables. Switching is one attribute on <html>, applied before first paint so there is no color flash.
  3. Manifest-driven content sections. Tools, Showcase, Writing, Testimonials, Projects all read from JSON. Future-me adds entries without touching HTML.
  4. Compute, never type, anything time-based. Job tenure, years in tech and day counts all derive from a start date, so copy that states a duration cannot drift out of date.
  5. Placeholder testimonials never render. Sample entries carry a _sample flag and the loader skips them. A visitor cannot tell a placeholder quote from a real one, so it should never reach them.

Features Built

  • Dark/light theme toggle applied before first paint, no color flash
  • Live tenure counter (years / months / weeks / days), computed from a start date
  • Manifest-driven Tools, Showcase, Writing, Testimonials and Projects pages
  • Availability meter whose next-start date is always today + lead time
  • Scope estimator anchored on the published pricing tiers
  • A4-print résumé sheet and per-project case-study print styles
  • AJAX contact form with inline status, honeypot, and a working no-JS fallback
  • Offline-capable service worker: network-first for pages, cache-first for images
  • Keyboard jumps (g then h/w/a/c)

Lessons Learned

  • CSS variables > theme rebuilds. Light mode is ~20 lines of variable overrides. The token setup pays for itself immediately.
  • Don't over-engineer. No bundler, no React, no framework, and after the 2026 rebuild no jQuery or Bootstrap either. Vanilla does the job and the page stays fast.
  • Manifest-driven everything. Every page that is a list reads a JSON file. Adding content is editing data, not layout.
  • Minimal is not the same as empty. The first pass of the rebuild cut the clutter but left dead space, and it read as unfinished. Restraint still needs density: bordered panels, real images, tight spacing.
  • Measure the images. The portrait was a 1.4 MB, 3215×4286 JPEG. Downscaling the image set took it from 6.5 MB to 520 KB, which matters a lot on mobile data.

Outcome

Live at the URL you are on now. Installable as a PWA, works offline, and ships with no JavaScript dependencies at all. Twelve pages became five, custom.css went from 268 KB to one token-driven stylesheet, and ~370 KB of vendor JavaScript came out entirely.

Everything that is a list reads from a JSON manifest, so new tools, posts, projects and demos go in without touching layout code. The portfolio is its own ongoing project.
